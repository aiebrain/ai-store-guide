2. 프론트엔드 — Lovable + Vercel

2-1. Lovable이란?

문장(프롬프트)을 입력하면 AI가 React + TailwindCSS 코드를 자동 생성해주는 서비스입니다.

코딩을 전혀 몰라도 프로페셔널한 쇼핑몰 화면을 만들 수 있습니다.

💡 Lovable의 강점

- 프롬프트 → 즉시 화면 생성 (30초 이내)

- 수정도 프롬프트로 ("헤더 색상 검정으로 바꿔줘")

- 반응형(모바일) 자동 지원

- GitHub 자동 연동 → Vercel 배포까지 원클릭

2-2. Lovable 시작하기

  1. lovable.dev 가입
  2. "New Project" 클릭
  3. 아래 프롬프트를 입력:

한국어 쇼핑몰을 만들어줘.

필요한 페이지:
- 메인 (히어로 배너 + 인기 상품 그리드 4열)
- 상품 목록 (카테고리 필터 + 검색바)
- 상품 상세 (이미지 갤러리 + 옵션 선택 + 장바구니 담기)
- 장바구니 (수량 변경 + 삭제 + 총액 계산)
- 결제 페이지 (배송지 입력 + 결제수단 선택)
- 마이페이지 (주문 내역 + 배송 추적)
- 로그인/회원가입 (카카오/구글 소셜 로그인)

디자인:
- 미니멀, 화이트 배경
- 라운드 카드 (border-radius: 12px)
- 모바일 우선 반응형
  1. AI가 생성한 결과물 확인 → 수정 사항은 채팅으로 요청
📝 수정 프롬프트 예시

`

- 헤더에 로고를 왼쪽으로, 장바구니 아이콘을 오른쪽에 추가해줘

- 상품 카드에 할인율 빨간 뱃지 추가해줘 (예: -30%)

- 장바구니 아이콘에 담긴 상품 수 뱃지 표시해줘

- 푸터에 고객센터 전화번호와 이메일 추가해줘

`

2-3. Vercel 배포

Lovable에서 만든 코드를 전 세계에 공개하는 단계입니다.

단계:

  1. Lovable → "Deploy" 버튼 → GitHub 자동 push
  2. vercel.com 가입 (GitHub 계정으로)
  3. "Import Project" → Lovable이 만든 레포 선택
  4. "Deploy" 클릭 → 30초 내 배포 완료!

자동 배포 흐름:
Lovable에서 수정 → GitHub 자동 push → Vercel 자동 빌드 → 30초 후 반영
✅ Vercel 무료 플랜

- 월 100GB 트래픽 (소규모 쇼핑몰 충분)

- HTTPS(SSL) 자동 적용

- 글로벌 CDN (전 세계 빠른 로딩)

- Preview 배포 (수정 사항 라이브 전 미리 확인)

2-4. 도메인 연결

  1. 도메인 구매: 가비아, 호스팅KR 등 (연 1~2만원)
  2. Vercel → Settings → Domains → 구매한 도메인 입력
  3. 도메인 DNS 설정에서 CNAME 레코드 추가:

    4. - 호스트: @ 또는 www

    - 값: cname.vercel-dns.com

  4. 5~30분 후 SSL 자동 적용 → https://yourbrand.com 접속 가능!

3. 백엔드 — Supabase

3-1. Supabase란?

Firebase의 오픈소스 대안으로, 데이터베이스 + 인증 + 파일 저장을 한 곳에서 제공합니다.

관리 화면에서 클릭만으로 설정 가능 — 코딩 불필요.

💡 왜 Supabase?

- 무료 플랜: DB 500MB + Storage 1GB (시작 충분)

- 카카오/구글 소셜 로그인 내장

- 실시간 데이터 동기화 (주문 상태 즉시 반영)

- SQL Editor 내장 (복붙만으로 테이블 생성)

3-2. 프로젝트 생성

  1. supabase.com 가입 (GitHub 계정)
  2. "New Project" → 이름 입력
  3. 리전: Northeast Asia (Tokyo) 선택 (한국에서 가장 빠름)
  4. DB 비밀번호 설정 → "Create"

3-3. 데이터베이스 스키마

Supabase → SQL Editor → 아래 SQL을 복사-붙여넣기 → Run

📌 복붙만 하면 됩니다

아래 코드를 이해할 필요 없어요. 그냥 복사해서 SQL Editor에 붙여넣고 실행하면 테이블이 자동으로 만들어집니다.

회원 테이블:


CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id),
  name TEXT,
  phone TEXT,
  address TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

상품 테이블:


CREATE TABLE products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name TEXT NOT NULL,
  description TEXT,
  price INTEGER NOT NULL,
  sale_price INTEGER,
  category TEXT,
  image_urls TEXT[],
  stock INTEGER DEFAULT 0,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMPTZ DEFAULT now()
);

주문 테이블:


CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES profiles(id),
  status TEXT DEFAULT 'pending',
  total_amount INTEGER NOT NULL,
  shipping_address TEXT,
  payment_method TEXT,
  payment_key TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

주문 상품 테이블:


CREATE TABLE order_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id),
  product_id UUID REFERENCES products(id),
  quantity INTEGER NOT NULL,
  price INTEGER NOT NULL,
  options JSONB
);

3-4. 소셜 로그인 설정

카카오 로그인

  1. developers.kakao.com → 앱 생성
  2. 카카오 로그인 → 활성화
  3. Redirect URI 등록:
    4. 
   https://YOUR_PROJECT.supabase.co/auth/v1/callback
  4. Supabase → Auth → Providers → Kakao
  5. Client ID, Client Secret 입력 → 저장

구글 로그인

  1. console.cloud.google.com → OAuth 클라이언트 생성
  2. Redirect URI 동일하게 설정
  3. Supabase → Auth → Providers → Google → ID/Secret 입력
💡 소셜 로그인 왜 중요한가?

일반 이메일 회원가입 전환율: 약 20%

카카오 로그인 전환율: 약 60~70% (3배 이상!)

한국 유저 대부분은 카카오 로그인을 기대합니다.

3-5. Storage (파일 저장)

  1. Supabase → Storage → New Bucket → product-images
  2. Public 체크 (상품 이미지 공개 접근)
  3. 파일 크기 제한: 5MB
  4. 허용 파일: image/jpeg, image/png, image/webp

3-6. Edge Functions

📋 Edge Functions이란?

서버 없이 실행되는 작은 코드 조각입니다.

결제 확인, 알림 발송 같은 백엔드 로직을 처리합니다.

함수 역할
handle-payment Toss/Rapyd 결제 확인 후 주문 상태 업데이트

4. 결제 연동 — Toss + Rapyd

4-1. 결제 분기 구조


고객이 "결제하기" 클릭
  │
  ├─ 🇰🇷 국내 결제 선택 → Toss Payments
  │   ├─ 신용/체크카드
  │   ├─ 카카오페이
  │   ├─ 네이버페이
  │   └─ 계좌이체
  │
  └─ 🌍 해외 결제 선택 → Rapyd
      ├─ Visa / Mastercard
      ├─ PayPal
      ├─ Apple Pay
      └─ Google Pay

4-2. Toss Payments (국내)

✅ 국내 결제 1위

카드/카카오페이/네이버페이/계좌이체 — 한국 고객 결제의 95% 커버

연동 단계:

  1. developers.tosspayments.com 가입
  2. 사업자등록번호 인증 → API 키 발급
  3. 2개의 키를 받게 됩니다:

    4. - 클라이언트 키 → 프론트엔드 (결제창 호출용)

    - 시크릿 키 → Supabase Edge Function (결제 승인용)

결제 흐름:


1. 고객 "결제하기" 클릭
2. → Toss 결제창 팝업 (카드번호 입력 또는 카카오페이 선택)
3. → 결제 완료 → paymentKey 반환
4. → Supabase Edge Function에서 결제 승인 API 호출
5. → 성공 시 orders 테이블 상태 → 'paid'
6. → 카카오 알림톡 자동 발송

수수료:

결제 수단 수수료
신용카드 3.3%
카카오페이 3.3%
네이버페이 3.3%
계좌이체 1.5%
가상계좌 건당 300원

4-3. Rapyd (글로벌)

ℹ️ 해외 고객도 결제 가능

전 세계 900개+ 결제 수단 지원. 해외 판매 시 필수.

연동 단계:

  1. rapyd.net 가입
  2. 테스트 모드 → API 키 발급 (Access Key + Secret Key)
  3. Hosted Checkout 방식 사용 (가장 간단):

    4. - Edge Function에서 Checkout 객체 생성

    - 고객을 Rapyd 결제 페이지로 리다이렉트

    - 결제 완료 → Webhook으로 결과 수신

  4. 테스트 완료 후 → 본인인증 → 라이브 모드 전환

수수료: 결제 수단별 상이 (약 2.9% + $0.30)

⚠️ 사업자 요건

- Toss: 한국 사업자등록증 필수

- Rapyd: 해외 법인 또는 한국 사업자 가능 (KYB 인증 필요)

5. 부가 기능 연동

"나이키 운도화" → "나이키 운동화" 자동 보정!

6. AI 운영 자동화 — n8n + Claude

📋 핵심 개념

n8n은 자동화 도구 (Zapier 오픈소스 대안)이고, Claude API는 AI 두뇌입니다.

이 둘을 연결하면 "주문이 들어오면 → AI가 자동으로 처리"하는 시스템이 됩니다.

6-1. 주문 알림 자동화


🛒 신규 주문 발생 (Supabase Webhook)
  → n8n이 감지
  → 알리고 API → 카카오 알림톡 발송 (고객에게)
  → 텔레그램/이메일 알림 (셀러에게)

6-2. 리뷰 답글 자동화


⭐ 고객이 리뷰 작성 (Supabase INSERT 트리거)

9. 자주 묻는 질문 (FAQ)

❓ Q. 코딩을 전혀 모르는데 정말 가능한가요?

네. Lovable이 UI를, Supabase가 백엔드를 자동 처리합니다. SQL도 복사-붙여넣기만 하면 됩니다. 막히면 ChatGPT/Claude에게 물어보세요.

❓ Q. 사업자등록증이 꼭 필요한가요?

Toss Payments 연동 시 필수입니다. 간이과세자도 가능합니다. 홈택스에서 온라인 신청 가능 (3~5일 소요).

❓ Q. Cafe24나 Shopify 대비 장점은?

월정액 없이 시작 가능하고, 디자인/기능 커스터마이징이 완전히 자유롭습니다. 단, 초기 셋업에 시간이 조금 더 걸립니다 (2주 vs 1~2일).

❓ Q. 해외 판매도 가능한가요?

네. Rapyd로 글로벌 결제 + Lovable에서 다국어(i18n) 기능을 프롬프트로 추가하면 됩니다.

❓ Q. 트래픽이 갑자기 늘어나면?

Vercel은 자동 스케일링이고, Supabase도 Pro부터 자동 확장됩니다. 별도 서버 관리 불필요.

❓ Q. 기존 쇼핑몰(Cafe24 등)에서 이전 가능한가요?

가능합니다. 상품 데이터를 CSV로 내보내기 → Supabase DB에 임포트하면 됩니다.
